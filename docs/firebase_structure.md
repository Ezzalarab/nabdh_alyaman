# تحليل هيكل بيانات Firebase Firestore (المشروع الحالي)

يحتوي المشروع على المجموعات (Collections) التالية في Firestore. تم استنتاج هذا الهيكل من الكود المصدري (Entities & Repositories).

---

## 1. مجموعة المتبرعين (`donors`)
تخزن بيانات الأشخاص المسجلين كمتبرعين بالدم.

| الحقل | النوع | الوصف |
| :--- | :--- | :--- |
| `name` | String | اسم المتبرع |
| `email` | String | البريد الإلكتروني |
| `password` | String | كلمة المرور (مشفرة) |
| `phone` | String | رقم الهاتف |
| `blood_type` | String | فصيلة الدم (مثال: A+, O-) |
| `state` | String | المحافظة |
| `district` | String | المديرية |
| `neighborhood` | String | الحي/المنطقة |
| `lat` | String | خط العرض (موقع GPS) |
| `lon` | String | خط الطول (موقع GPS) |
| `image` | String | رابط الصورة الشخصية |
| `brith_date` | String | تاريخ الميلاد |
| `is_shown` | String | حالة ظهور المتبرع (0 أو 1) |
| `is_shown_phone` | String | ظهور رقم الهاتف (0 أو 1) |
| `is_gps_on` | String | حالة تفعيل الـ GPS |
| `token` | String | رمز FCM للإشعارات |
| `status` | String | حالة الحساب (Active/Blocked) |
| `created_at` | Timestamp | تاريخ التسجيل |

---

## 2. مجموعة مراكز الدم (`centers`)
تخزن بيانات المستشفيات أو بنوك الدم ومخزونها.

| الحقل | النوع | الوصف |
| :--- | :--- | :--- |
| `name` | String | اسم المركز |
| `email` | String | البريد الإلكتروني |
| `password` | String | كلمة المرور (مشفرة) |
| `phone` | String | رقم الهاتف |
| `state` | String | المحافظة |
| `district` | String | المديرية |
| `neighborhood` | String | الحي/المنطقة |
| `lat` | String | الموقع الجغرافي (Lat) |
| `lon` | String | الموقع الجغرافي (Lon) |
| `image` | String | رابط صورة المركز |
| `last_update` | String | تاريخ آخر تحديث للمخزون |
| `status` | String | حالة المركز |
| `A+`, `A-`, `B+`, ... | Number | عدد الوحدات المتوفرة لكل فصيلة |

---

## 3. مجموعة بيانات التطبيق العامة (`global_app_data`)
تخزن إعدادات التطبيق، النصوص التعريفية، والصور الرئيسية.

- `app_name`: اسم التطبيق.
- `about_app`: نص تعريفي عن التطبيق.
- `home_header`: عنوان الصفحة الرئيسية.
- `info_list`: قائمة تعليمات أو معلومات (تخزن كـ JSON string غالباً).
- `home_slides`: الروابط أو أسماء ملفات الصور في الـ Slider.
- `events_cards_data`: بيانات البطاقات التعريفية أو الفعاليات.

---

## 4. مجموعات أخرى
- **`notifications`**: تخزن سجل الإشعارات المرسلة.
- **`search_logs`**: سجل عمليات البحث التي قام بها المستخدمون لتتبع الطلب على الفصائل.
- **`updating`**: معلومات الإصدار الجديد ورابط التحديث.
- **`users_per_day`**: إحصائيات يومية لعدد المستخدمين.

# جرد شامل وكامل لجميع كيانات وبيانات مشروع "نبض اليمن" (Current Database Inventory)

هذا المستند يحتوي على جرد تفصيلي لجميع المجموعات (Collections) والحقول (Fields) الموجودة حالياً في قاعدة بيانات Firebase Firestore الخاصة بالموقع، بناءً على التحليل العميق للكود المصدري (Entities, Repositories, Cubits) والبيانات الفعلية.

---

## 1. مجموعة المتبرعين (`donors`)
تُستخدم لتخزين بيانات الأشخاص المتطوعين للتبرع بالدم.

| اسم الحقل | النوع | الوصف | ملاحظات |
| :--- | :--- | :--- | :--- |
| `id` | String | المعرف الفريد للوثيقة (Doc ID) | مطابق لـ UID الخاص بـ Firebase Auth |
| `name` | String | اسم المتبرع | |
| `email` | String | البريد الإلكتروني | |
| `password` | String | كلمة المرور | تُخزن مشفرة (Encoded) في المستودع |
| `phone` | String | رقم الهاتف | بدون رمز الدولة غالباً |
| `blood_type` | String | فصيلة الدم | قيم مثل: A+, O-, الخ |
| `gender` | String | الجنس | ذكر/أنثى (وجدت في عينات البيانات) |
| `state` | String | المحافظة | |
| `district` | String | المديرية | |
| `neighborhood` | String | الحي / المنطقة | |
| `image` | String | رابط الصورة الشخصية | |
| `brith_date` | String | تاريخ الميلاد | |
| `is_shown` | String | حالة ظهور المتبرع | "0" مخفي، "1" ظاهر |
| `is_shown_phone` | String | حالة ظهور الهاتف | "0" مخفي، "1" ظاهر |
| `is_gps_on` | String | تفعيل تحديد الموقع | "0" معطل، "1" مفعل |
| `token` | String | رمز FCM | لإرسال الإشعارات للمتبرع |
| `lat` | String | خط العرض (Latitude) | الموقع الجغرافي |
| `lon` | String | خط الطول (Longitude) | الموقع الجغرافي |
| `status` | String | حالة الحساب | مثال: "ACTIVE" |
| `created_at` | Timestamp | تاريخ الإنشاء | يتم إضافته عند التسجيل |

## 7. مجموعة البيانات العامة والـ CMS (`global_app_data`)
تحتوي على إعدادات التطبيق والمحتوى الديناميكي للواجهات.

### الحقول الأساسية:
| الحقل | النوع | الوصف |
| :--- | :--- | :--- |
| `app_name` | String | اسم التطبيق |
| `about_app` | String | نص "حول التطبيق" |
| `home_header` | String | العنوان الرأس في الصفحة الرئيسية |
| `info_titile` | String | عنوان قسم الفوائد |
| `report_link` | String | رابط الإبلاغ عن مشكلة (WhatsApp) |
| `events_title` | String | عنوان قسم المستجدات |
| `info_list` | JSON String | قائمة فوائد التبرع (Convert to List<String>) |
| `home_slides` | List<String> | روابط صور الـ Slider |
| `events_cards_data`| JSON String | قائمة بيانات الفعاليات (List of Objects) |

### تفاصيل كيان الفعالية (`EventCardData`):
- `id`: المعرف.
- `title`: العنوان.
- `desc`: الوصف.
- `image`: صورة الفعالية.
- `date`: وقت الفعالية.
- `place`: مكان الفعالية.
- `link`: رابط إضافي.

---

> [!IMPORTANT]
> تم استخراج هذه البيانات بدقة من ملفات `domain/entities` ومستودعات البيانات `data/repositories` ومنطق الـ `Cubit`. هذا الجرد شامل ولا يتضمن أي اقتراحات لهيكلة جديدة، بل يصف الواقع الحالي للمشروع.

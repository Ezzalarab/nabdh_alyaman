# 07 — المركز والمخزون

## الهدف

تمكين دور **CENTER** من إدارة الملف والمخزون عبر API بدل مستند Firestore `centers/{uid}`.

## الوضع الحالي

| الملف | السلوك |
|-------|--------|
| `sign_up_center_usecase.dart` | تسجيل مركز عبر Firebase |
| `sing_up_center_page.dart` | UI تسجيل |
| `profile_center.dart`, `edit_main_center_data.dart` | ملف المركز |
| `blood_center.dart` | entity بحقول Firestore |
| `home_drawer_center_body.dart` | `FirebaseAuth.signOut` |

## API المرجعي

[`docs/backend_guide/api/centers-and-inventory.md`](../../backend_guide/api/centers-and-inventory.md)

| Method | Path | Auth |
|--------|------|------|
| GET | `/centers/me` | CENTER |
| PATCH | `/centers/me` | CENTER |
| PATCH | `/centers/me/stock` | CENTER — `{ bloodType, change, reason }` |
| GET | `/centers/me/stock/history` | CENTER |
| POST | `/centers/me/donations` | CENTER — `{ donorId, notes }` |
| GET | `/centers`, `/centers/:id`, `/centers/:id/stock` | عام (للبحث العام) |

**لا ننفّذ:** `POST /admin/centers` (خارج نطاق التطبيق).

## CenterBloc

### Events (أمثلة)

- `CenterProfileLoadRequested`
- `CenterProfileUpdateSubmitted`
- `CenterStockLoadRequested`
- `CenterStockAdjustSubmitted` (bloodType, change +/-, reason)
- `CenterDonationRecordSubmitted` (donorId, notes)
- `CenterStockHistoryLoadRequested` (cursor pagination)

### States

- `CenterLoading`, `CenterProfileLoaded`, `CenterStockLoaded`, `CenterFailure`

## تسجيل المركز

- **إزالة** تدفق `SignUpCenter` عبر Firebase.
- شاشة `sing_up_center_page`: تحويل إلى معلومات "يتم إنشاء حساب المركز من الإدارة" + زر للاتصال/الدخول فقط.
- الدخول: نفس `AuthBloc` مع توجيه `role == CENTER` إلى dashboard.

## UI مقترحة

```text
presentation/pages/center/
  center_dashboard_page.dart    # ملخص مخزون
  center_stock_page.dart        # تعديل الكميات
  center_donation_page.dart     # تسجيل تبرع
  center_profile_edit_page.dart
```

## Mapping `BloodCenter`

| Firestore | API |
|-----------|-----|
| `center_name` | `name` |
| `stocks` map | `GET /centers/me` + stock endpoint |
| `location` | `lat`, `lon`, `locationId` |

## الملفات — إنشاء / تعديل / حذف

| إجراء | مسار |
|-------|------|
| إنشاء | `center_remote_datasource.dart`, `presentation/blocs/center/` |
| إنشاء | صفحات `center/*` |
| تعديل | `home_drawer_center_body.dart` — `AuthLogoutRequested` بدل `FirebaseAuth.signOut` |
| **حذف في نفس المرحلة** | أي cubit خاص بالمركز إن وُجد لاحقاً |
| حذف/تعطيل | `sign_up_center_usecase` Firebase |
| تعديل | `blood_center.dart` entity |

## معايير قبول

- [ ] CENTER يسجل دخول ويرى مخزونه.
- [ ] تعديل stock بـ `change` يعكس فوراً (مع 400 إن النقص > المتاح).
- [ ] تسجيل تبرع `POST /centers/me/donations` ينجح.
- [ ] DONOR لا يصل لشاشات المركز (403 + redirect).
- [ ] لا Firestore `centers` collection.

## مخاطر

| الخطر | التخفيف |
|-------|---------|
| بيئة الإنتاج لا تطابق تحديث `eligibleUntil` الموثّق في API | راجع `POST /centers/me/donations` في [centers-and-inventory](../../backend_guide/api/centers-and-inventory.md)؛ العميل يعرض ما يعيده API فقط |
| حسابات مركز قديمة بدون API | OTP + دعم |

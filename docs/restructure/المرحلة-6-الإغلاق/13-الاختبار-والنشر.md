## الأداء

- cold start < 3s على جهاز متوسط (هدف).
- ضغط صور قبل upload.
- Drift queries indexed على `stateId`.

## النشر

### إصدار

1. رفع `version` في `pubspec.yaml`.
2. `flutter build appbundle --dart-define=API_BASE_URL=https://nabdh.telqaia.com/api/v1`
3. Play Console → internal testing → production.

### تواصل المستخدمين

- إصدار يتطلب تسجيل دخول جديد (لا Firebase).
- نص داخل التطبيق: "حدّث كلمة المرور عبر نسيت كلمة المرور".

### مراقبة

- تتبع أخطاء API (إن وُجد Sentry لاحقاً).
- مراجعة `/admin/stats` من السيرفر (ليس في التطبيق).

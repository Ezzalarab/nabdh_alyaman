# 11 — مراجعة نهائية وإزالة البقايا

## الهدف

**تدقيق** المشروع بعد المراحل 0–5 — التأكد من عدم بقاء Cubit أو Firestore/Hive. هذه المرحلة **ليست** الموعد الأول لاستبدال Bloc (يحدث في كل مرحلة سابقة).

## جدول الاستبدال (مرجع — رقم المرحلة الصحيح)

| Cubit الحالي | Bloc البديل | يُستبدل في المرحلة |
|--------------|-------------|-------------------|
| `SignInCubit` / `SignUpCubit` | `AuthBloc` | **1** |
| `ProfileCubit` | `ProfileBloc` | **2** |
| `SearchCubit` / `MapsCubit` | `SearchBloc` (+ تمرير للخريطة) | **2** |
| `GlobalCubit` | `AppConfigBloc` | **4** |
| `SendNotficationCubit` | `NotificationsBloc` | **4** |

## قائمة تدقيق (مرحلة 11)

### Cubit / Bloc

```bash
rg "Cubit" lib/ --glob "*.dart"
rg "presentation/cubit" lib/
```

- [ ] لا مجلد `lib/presentation/cubit/` (أو فارغ).
- [ ] كل الصفحات تستخدم `Bloc`/`BlocBuilder`/`BlocConsumer`.

### Firebase (غير FCM)

```bash
rg "firebase_auth|cloud_firestore|firebase_storage|FirebaseFirestore|FirebaseAuth" lib/
```

- [ ] لا استيرادات أعلاه.
- [ ] `pubspec.yaml` لا يحتوي `cloud_firestore`, `firebase_auth`, `firebase_storage`, `firebase_app_check`.

### Hive

```bash
rg "hive|Hive" lib/ pubspec.yaml
```

- [ ] لا Hive.

### DI

- [ ] لا `initSignIn` / `initSignUp`.
- [ ] لا `gi<SignInCubit>()` في `main.dart`.

### ملفات يُفترض حذفها

```text
lib/presentation/cubit/**          # الكل
lib/core/firebase_analyzer.dart
lib/core/update.dart               # إن استُبدل بـ AppConfigBloc
lib/data/models/compare_hive_firbaase.dart
lib/data/models/donor_hive_data.dart
lib/data/repositories/send_notfication_impl.dart
```

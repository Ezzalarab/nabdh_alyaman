# 04 — المصادقة والهجرة

## الهدف

استبدال Firebase Auth بـ REST auth، `AuthBloc` موحّد للمتبرع والمركز، ومسار OTP **لنسيان كلمة المرور فقط** (ليس لتسجيل حساب جديد).

## الوضع الحالي

| الملف | السلوك |
|-------|--------|
| `auth_repo_impl.dart` | `FirebaseAuth` + كتابة Firestore |
| `signin_cubit.dart` | login + FCM token → Firestore |
| `signup_cubit.dart` | تسجيل + **Firebase Phone OTP** (لا يوجد مكافئ في API) |
| `sign_in_page.dart`, `sign_up_page.dart` | UI |
| `check_active.dart` | `currentUser` من Firebase |

## API المرجعي

[`docs/backend_guide/api/authentication.md`](../../backend_guide/api/authentication.md)

| Endpoint | استخدام |
|----------|---------|
| `POST /auth/login` | `identifier` = هاتف يمني أو email |
| `POST /auth/register` | DONOR فقط |
| `POST /auth/refresh` | تجديد access |
| `POST /auth/logout` | refresh + deviceToken |
| `DELETE /auth/account` | حذف حساب |
| `POST /auth/device` | FCM token |
| `POST /auth/forgot-password` | `{ phone }` |
| `POST /auth/verify-otp` | `{ phone, code }` → resetToken |
| `POST /auth/reset-password` | resetToken + newPassword |

**لا نستخدم** `POST /auth/migration/complete` (لا firebase_auth في العميل).

### تسجيل حساب جديد (تغيير UX — مهم)

| القديم (Firebase) | الجديد (API) |
|-------------------|--------------|
| `verifyPhoneNumber` + OTP | `POST /auth/register` بهاتف **967…** + **كلمة مرور** + حقول المتبرع |
| التحقق من تكرار الهاتف عبر Firestore | **400** من السيرفر — اعرض "سجّل الدخول أو نسيت كلمة المرور" |
| خطوتان (auth ثم بيانات) | يُفضّل نموذج واحد أو خطوتان لكن **بدون OTP تسجيل** |

### مستخدمون مهاجرون (بدون Firebase في العميل)

عند login: `403` + `code: "NEEDS_FIREBASE_PASSWORD"` → وجّه مباشرة لشاشة **نسيت كلمة المرور** (نفس OTP API)، لا تحاول Firebase.

### تطبيع الهاتف

- أرسل للسيرفر بصيغة موحّدة: `967` + 9 أرقام (بدون `+` في JSON ما لم يُطلب).
- UI قد تعرض `+967` للمستخدم.

### استجابة login ناجحة (201)

```json
{
  "accessToken": "...",
  "refreshToken": "...",
  "role": "DONOR",
  "user": { "id": 1, "phone": "967771234567", "role": "DONOR" }
}
```

## AuthBloc — أحداث وحالات

### Events

| Event | وصف |
|-------|-----|
| `AuthCheckRequested` | عند فتح التطبيق — قراءة tokens |
| `AuthLoginSubmitted` | identifier + password |
| `AuthRegisterDonorSubmitted` | حقول التسجيل |
| `AuthLogoutRequested` | logout + مسح محلي |
| `AuthForgotPasswordSubmitted` | phone |
| `AuthOtpVerified` | phone + code |
| `AuthPasswordResetSubmitted` | resetToken + password |
| `AuthSessionExpired` | من interceptor |
| `AuthPasswordResetTokenReceived` | بعد verify-otp (احتفظ بـ resetToken في state آمن) |

### States

| State | UI |
|-------|-----|
| `AuthInitial` | splash |
| `AuthLoading` | مؤشر |
| `AuthAuthenticated` | role + user |
| `AuthUnauthenticated` | sign in |
| `AuthFailure` | رسالة عربية |

### Mapping حقول التسجيل (DONOR)

| UI / Entity قديم | API register |
|------------------|--------------|
| fullName | `fullName` |
| phone | `phone` (9677...) |
| password | `password` |
| bloodType | `bloodType` |
| gender | `MALE` / `FEMALE` |
| email | `email`? |
| state/district | `stateId`, `districtId`, `locationId` |
| lat/lon | `lat`, `lon` |

### تسجيل المركز (CENTER)

- لا `POST /auth/register` للمركز — الحساب يُنشأ من الأدمن (`POST /admin/centers`).
- في التطبيق: **تسجيل دخول فقط** لـ CENTER عبر `POST /auth/login`.
- إزالة أو تعطيل `sing_up_center_page.dart` كتسجيل ذاتي — أو تحويلها لطلب "تواصل مع الإدارة".

## FCM عند login

1. `FirebaseMessaging.instance.getToken()`
2. `POST /auth/device` مع JWT: `{ token, platform: "android" }`
3. عند logout: أرسل `deviceToken` في body logout

## معايير قبول

- [ ] تسجيل دخول DONOR + CENTER عبر API.
- [ ] إعادة فتح التطبيق يحافظ على الجلسة (secure storage).
- [ ] logout يمسح tokens ويوجّه لشاشة الدخول.
- [ ] تسجيل متبرع جديد بكلمة مرور (بدون OTP تسجيل).
- [ ] OTP: forgot → verify → reset يعمل end-to-end.
- [ ] `NEEDS_FIREBASE_PASSWORD` → توجيه لنسيت كلمة المرور.
- [ ] مستخدم BLOCKED → رسالة 403 واضحة.
- [ ] `POST /auth/logout` يُستدعى قبل مسح التخزين المحلي.
- [ ] لا `FirebaseAuth` في `lib/`.
- [ ] حذف مجلدات `signin_cubit` و `signup_cubit`.

## مخاطر

| الخطر | التخفيف |
|-------|---------|
| مستخدمون بريد فقط بدون هاتف | دعم `identifier` email في login |
| رفض OTP التسجيل من المستخدمين | نص توضيحي + دعم |
| تسجيل مركز ذاتي كان موجوداً | UX جديد + نص توضيحي |
| `forgot-password` دائماً 200 | لا تكشف وجود الرقم — UX موحّد |

## تحسينات مقترحة (لم تُنفَّذ برمجياً)

- إضافة `go_router` أو توحيد التنقل (الدليل يذكره كخيار) — **مؤجَّل افتراضياً**؛ انظر قسم «قرارات اختيارية» في [README إعادة الهيكلة](README.md).
- `FileUrlResolver` مركزي لـ `fileId` → URL — **مخطَّط افتراضياً مع المرحلة 4**؛ نفس القسم.
- `bloc_test` من مرحلة 1 لـ AuthBloc — **موصى به**؛ نفس القسم.
- flavors: `dev` / `prod` بدل `--dart-define` فقط (اختياري) — **مؤجَّل افتراضياً**؛ نفس القسم.

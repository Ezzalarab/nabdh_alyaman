# متطلبات الباكإند — منطق يُنقل من العميل

هذا المجلد يوثّق **عمليات وقواعد أعمال** كانت تُنفَّذ في تطبيق Flutter/Firebase ويجب أن تكون مسؤولية **السيرفر** (كلياً أو جزئياً). موجّه لفريق الباكإند والموبايل معاً.

## كيف تقرأ الجداول

| الحالة | المعنى |
|--------|--------|
| **موجود** | API موثّق في `docs/backend_guide/` — العميل يستهلكه فقط |
| **جزئي** | يوجد أساس لكن ينقصه سلوك كان في العميل |
| **مطلوب** | لا بديل حالياً — يُنصح بتصميم endpoint أو توسيع موجود |
| **أمان** | يجب إيقافه في العميل فوراً — سرّ أو صلاحية على السيرفر فقط |

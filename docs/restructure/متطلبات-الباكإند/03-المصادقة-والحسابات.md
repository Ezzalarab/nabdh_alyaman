## ما يوفّره الباكإند اليوم (**موجود**)

| Endpoint | يغطي |
|----------|--------|
| `POST /auth/register` | تسجيل DONOR — **400** إن الهاتف مكرر |
| `POST /auth/login` | identifier + password |
| `POST /auth/forgot-password` | OTP نسيان كلمة المرور |
| `POST /auth/verify-otp` / `reset-password` | إكمال reset |
| `POST /auth/migration/complete` | مهاجرون Firebase (العميل لن يستخدمه) |
| `POST /admin/centers` | إنشاء مركز (ADMIN) |
| Throttle login | 10 / 15 دقيقة |

## منطق يُنقل إلى الباكإند

### 1. التحقق من تكرار الهاتف — **موجود**

| العميل | الباكإند |
|--------|----------|
| query Firestore قبل OTP | `POST /auth/register` → 400 |

**لا endpoint إضافي مطلوب** — العميل يعالج 400 برسالة عربية.

### 2. حذف متبرع سابق بنفس الهاتف — **لا يُعاد في العميل**

كان `deletePreviousDonor` منطقاً لإصلاح بيانات Firebase.

| الباكإند | |
|----------|--|
| **لا** حذف تلقائي عند التسجيل | يمنع دمج حسابات بالخطأ |
| بديل | دعم `DELETE /auth/account` + إعادة تسجيل، أو دمج يدوي Admin |

### 3. حد التسجيل اليومي (`users_per_day`) — **مطلوب (P2)**

**العميل كان:**

```text
users_per_day/{YYYY-MM-DD}.users_count
إذا >= 10 → منع تسجيل هاتف (منطق معطوب جزئياً في الكود)
```

**مقترح باكإند:**

| خيار | تنفيذ |
|------|--------|
| A | Rate limit على `POST /auth/register` per IP + `x-device-id` (موجود throttle عام) |
| B | قاعدة أعمال: max N تسجيلات DONOR جديدة / يوم / دولة — **429** برسالة واضحة |
| C | إعداد في `app-config`: `max_registrations_per_day` |

**توصية:** B + C للمرونة — لا Firestore.

### 4. تسجيل المركز ذاتي — **قرار منتج (موجود جزئياً)**

| العميل | الباكإند |
|--------|----------|
| `sign_up_center` Firebase | فقط `POST /admin/centers` |

**لا تغيير API مطلوب** — التطبيق يزيل التسجيل الذاتي. إن رُغب لاحقاً: `POST /centers/register-request` (طلب معلّق) خارج نطاق الهجرة الحالية.

### 5. ربط الحساب بملف المتبرع — **موجود**

| Firebase | API |
|----------|-----|
| إنشاء `donors/{uid}` بعد Auth | بيانات ضمن `POST /auth/register` + `GET/PATCH /donors/me` |

**لا منطق إضافي** — تأكد أن register يخلق `DonorProfile` كاملاً.

### 6. مستخدمون بلا كلمة مرور محلية — **موجود**

`403` + `NEEDS_FIREBASE_PASSWORD` → العميل يوجّه لـ OTP reset (بدون Firebase SDK).

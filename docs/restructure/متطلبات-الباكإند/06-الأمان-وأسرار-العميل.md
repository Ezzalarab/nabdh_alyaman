# 06 — الأمان وأسرار العميل

## مشكلة حرجة (P0)

الملف `lib/core/app_constants.dart` يحتوي:

```dart
static const String baseUrl = 'https://fcm.googleapis.com/fcm/send';
static const String serverKey = '...';  // FCM Legacy Server Key
static const String senderId = '...';
```

**أي شخص يفكك APK يمكنه:**

- إرسال إشعارات باسم التطبيق.
- استهلاك حصة FCM.
- استهداف tokens مسرّبة في الكود (موجودة أيضاً في `send_notfication_impl.dart`).

## الإجراء المطلوب

| الطرف | إجراء |
|-------|--------|
| **باكإند** | FCM **فقط** عبر Firebase Admin SDK (متغيرات بيئة على السيرفر — ليست في Git للعميل) |
| **موبايل** | حذف `serverKey`, `senderId`, دوال HTTP FCM — الإبقاء على `firebase_messaging` للاستقبال فقط |
| **عمليات** | **تدوير (rotate)** Server Key الحالي في Firebase Console بعد إصدار التطبيق الجديد |

## أسرار مسموحة في العميل

| السر | مسموح؟ |
|------|--------|
| FCM Server Key | **لا** |
| JWT access/refresh | تخزين محلي مشفّر فقط — ليس في الكود |
| `API_BASE_URL` | نعم (ليس سراً) |
| Firebase `google-services.json` | نعم (معرف مشروع — ليس Admin) |
| `x-device-id` | معرف تثبيت — ليس سراً |

## Throttling ومنع إساءة

موجود في API (`THROTTLE_ENABLED`, حدود login/forgot/blood-requests).

**يُنصح بالتأكد:**

- [ ] لا endpoint عام يرسل FCM بدون JWT ADMIN.
- [ ] rate limit على أي broadcast مستقبلي.

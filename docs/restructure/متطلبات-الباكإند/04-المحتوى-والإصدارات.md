# 04 — المحتوى والإصدارات

## ما يفعله العميل اليوم

| الموقع | السلوك |
|--------|--------|
| `global_repo_impl.dart` | قراءة `global_app_data` من Firestore |
| `global_repo_impl.dart` | `FirebaseStorage.getDownloadURL` لـ `home_slider_images`, `events_images` |
| `update.dart` | الاستماع لـ collection `updating`: `new_version`, `show_dialog`, `message`, `waring_degree`, `update_link` |
| `splash_screen` / `home` | عرض السلايدر والفعاليات من الكيان المحلي |

## ما يوفّره الباكإند اليوم (**موجود جزئياً**)

| Endpoint | موثّق |
|----------|--------|
| `GET /app-config` | `app_name`, `home_header`, `min_app_version` |
| `GET /app-config/:key` | قيمة مفتاح واحد |
| `PUT /app-config/:key` | ADMIN فقط |
| `POST /files/upload` | رفع صور |
| `GET /files/:fileId` | عرض ملف |

## فجوات / مطلوب من الباكإند

### 1. محتوى الصفحة الرئيسية (سلايدر + فعاليات) — **مطلوب (P1)**

**Firestore القديم (مرجع للهجرة):**

```text
global_app_data:
  home_slider: [{ image path في Storage, ... }]
  events: [...]
  نصوص، إحصائيات، إلخ
```

**المطلوب في API:**

خيار **أ** — مفاتيح منفصلة (JSON string في `value`):

| مفتاح مقترح | نوع القيمة | ملاحظة |
|-------------|------------|--------|
| `home_slider` | JSON array | `{ "fileId": 12, "title": "...", "link": "..." }` |
| `home_events` | JSON array | فعاليات |
| `home_statistics` | JSON optional | إن كانت الإحصائيات ديناميكية |

خيار **ب** — endpoint مخصص:

```http
GET /app-content/home
→ { slider: [...], events: [...], header: "..." }
```

**معايير:**

- [ ] الصور عبر `fileId` وليس مسار Storage خام.
- [ ] `isPublic=true` للصور المعروضة للجميع.
- [ ] توثيق schema في `docs/3-frontend/api/` بعد التثبيت.

**إجراء فوري:** تصدير مستند `global_app_data` الحالي → إدخال في `app-config` أو سكربت seed.

### 2. إجبار التحديث — **موجود جزئياً**

| Firestore `updating` | API |
|---------------------|-----|
| `new_version`, `show_dialog`, `message`, `update_link` | `min_app_version` من `GET /app-config` |

**مطلوب توثيق/توسيع:**

| حقل اختياري في app-config | استخدام |
|---------------------------|---------|
| `force_update_message` | نص dialog عربي |
| `force_update_enabled` | `"true"` / `"false"` |
| `store_url_android` | رابط Play Store |

**العميل:** يقارن `package_info.version` مع `min_app_version` (semver). رابط المتجر يمكن ثابتاً في التطبيق (`Urls.googleStoreAppLink`) إن لم يُوفَّر من السيرفر.

### 3. إحصائيات الشاشة الرئيسية — **اختياري**

إن كانت `home_statistics` (متبرعين، طلبات…) تُحسب من Firestore:

| مقترح | |
|--------|--|
| `GET /app-content/home` يتضمن أرقاماً مجمّعة | أو |
| `GET /public/stats` | `{ donorsCount, centersCount, openRequests }` — قراءة فقط |

**ملاحظة:** `GET /admin/stats` للمشرف فقط — لا تستخدمه في تطبيق المتبرع.

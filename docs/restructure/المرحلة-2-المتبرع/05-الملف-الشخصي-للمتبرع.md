# 05 — الملف الشخصي للمتبرع

## الهدف

استبدال مستند Firestore `donors/{uid}` بـ `/donors/me` ورفع الصور عبر `/files/upload`.

## الوضع الحالي

| الملف | السلوك |

| `profile_cubit.dart` | تحديث بيانات |

## API المرجعي

[`docs/backend_guide/api/donors-and-search.md`](../../backend_guide/api/donors-and-search.md)

| Method | Path | Auth |
|--------|------|------|
| GET | `/donors/me` | JWT DONOR |
| PATCH | `/donors/me` | JWT DONOR |
| GET | `/donors/me/donations` | JWT DONOR |

### حقول PATCH شائعة

`fullName`, `bloodType`, `gender`, `birthDate`, `stateId`, `districtId`, `locationId`, `lat`, `lon`, `isShown`, `isPhoneShown`, `isNotificationsEnabled`, `isGpsOn`, `imageUrl` (fileId)

## ProfileBloc

### Events

- `ProfileLoadRequested`
- `ProfileUpdateSubmitted` (حقول جزئية)
- `ProfileImageUploadRequested` (File → compress → upload)

### States

- `ProfileInitial`, `ProfileLoading`, `ProfileLoaded(DonorProfile)`, `ProfileUpdateSuccess`, `ProfileFailure`

## رفع الصورة

1. ضغط الصورة (مثلاً `flutter_image_compress`)
2. `POST /files/upload` — `multipart`: `file`, `isPublic: "true"` للصورة الظاهرة في البحث
3. `PATCH /donors/me` — `{ "imageUrl": "<fileId>" }`
4. عرض الصورة: `imageUrl` في API = **`fileId` (رقم)** — أنشئ `FileUrlResolver` يبني URL عبر `GET /files/:fileId` أو base عام من السيرفر (راجع `files-and-app-config`: قد يستخدم Nginx redirect)

## Mapping Entity

حدّث `lib/domain/entities/donor.dart`:

| Firestore (قديم) | API |
|------------------|-----|
| `uid` | `userId` |
| `full_name` | `fullName` |
| `blood_type` | `bloodType` |
| `is_shown` | `isShown` |
| `token` | — (يُدار عبر `/auth/device`) |
| `eligible_until` | `eligibleUntil` |

أنشئ `DonorProfile` model في `data/models/donor_profile_dto.dart` مع `fromJson`.

## معايير قبول

- [ ] GET `/donors/me` يملأ شاشة الإعدادات.
- [ ] PATCH يحدّث الحقول ويعكس في UI.
- [ ] رفع صورة شخصية يظهر في البحث (isPublic=true).
- [ ] `GET /donors/me/donations` يعرض سجل التبرعات (إن وُجد UI).
- [ ] CENTER لا يستدعي `/donors/me` (403 متوقع — لا واجهة متبرع).

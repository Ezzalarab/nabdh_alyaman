# 06 — البحث والمواقع

## الهدف

استبدال استعلامات Firestore للبحث بـ `/donor-search` و `/centers`، وكاش المحافظات/المديريات في Drift.

## الوضع الحالي

| الملف | السلوك |
|-------|--------|
| `search_repo_impl.dart` | Firestore compound queries |
| `search_cubit.dart` | فلاتر في حقول عامة + فلترة district محلياً |
| `search_donors_uc.dart`, `search_centers_uc.dart` | use cases |
| `search_page.dart`, `search_options.dart` | UI |
| `search_map_page.dart`, `maps_cubit.dart` | خريطة |
| `csc_picker.dart` | محافظات من `data/country.json` محلي |

### بحث المتبرعين — وضعان

| Endpoint | متى تستخدمه | Query رئيسية |
|----------|-------------|--------------|
| `GET /donor-search` | GPS متاح | `bloodType`, `lat`, `lon` (**مطلوبان**), `radiusKm?` (افتراضي 20، أقصى 100), `stateId?` |
| `GET /donor-search/manual` | بدون GPS / فلتر محافظة | `bloodType`, `stateId?`, `districtId?`, `cursor?`, `limit?` |

- **جغرافي:** مصفوفة حتى **100** — بدون pagination.
- **يدوي:** `{ items, nextCursor, hasNextPage }`.

نتيجة: `userId`, `fullName`, `bloodType`, `imageUrl` (fileId), `phone?`, `distance_km?`

### فصائل الدم المتوافقة

المنطق الحالي في `lib/domain/entities/blood_types.dart` يبقى **في العميل** لتوسيع خيارات البحث — الـ API يستقبل `bloodType` واحداً؛ عند "عرض المتوافقين" أرسل عدة طلبات أو اختر النوع الأنسب (وثّق القرار في التنفيذ).

### المراكز

| Endpoint | ملاحظات |
|----------|---------|
| `GET /centers` | قائمة مراكز |
| `GET /centers/:id` | تفاصيل |
| `GET /centers/:id/stock` | مخزون الدم |

### المواقع

| Endpoint | ملاحظات |
|----------|---------|
| `GET /locations` | محافظات (STATE) |
| `GET /locations/:stateId/districts` | مديريات |

## SearchBloc — State موحّد

ضع الفلاتر في **State** لا حقول mutable على الـ Bloc:

```dart
// مثال مفاهيمي
class SearchState {
  final BloodType? bloodType;
  final int? stateId;
  final int? districtId;
  final double? lat;
  final double? lon;
  final List<DonorSearchResult> donors;
  final List<CenterSummary> centers;
  final SearchStatus status;
}
```

### Events

- `SearchFiltersChanged`
- `SearchRequested`
- `SearchLocationPermissionRequested`
- `SearchCentersLoadRequested`

## Locations — Drift + Remote

```mermaid
flowchart LR
  UI[SearchOptions] --> Bloc[SearchBloc]
  Bloc --> Repo[SearchRepository]
  Repo --> Local[LocationsLocalDS]
  Repo --> Remote[SearchRemoteDS]
  Local --> Drift[(Drift)]
  Remote --> API[/locations]
```

- عند أول حاجة: إن cache صالح → Drift؛ وإلا `GET /locations` → حفظ → عرض.
- **API مصدر الحقيقة**؛ `data/country.json` احتياطي offline مؤقت فقط.

### استبدال `csc_picker`

الحزمة `csc_picker` + `country.json` لا تطابق `stateId`/`districtId` من API. أنشئ:

```text
presentation/widgets/locations/
  state_district_picker.dart   # يقرأ من Drift/API
```

## MapsBloc

- **مفضّل:** تمرير `List<DonorSearchResult>` من `SearchBloc` إلى `SearchMapPage` عبر `GoRouter` extra أو constructor — تجنّب MapsBloc منفصل إن لم يكن مطلوباً.
- لا استعلام Firestore من الخريطة.

## search_logs

لا يكتب العميل سجلات بحث — **مسؤولية الباكإند** (تسجيل ضمني أو `POST /analytics/search`). التفاصيل: [`متطلبات-الباكإند/02-البحث-والتحليلات.md`](../متطلبات-الباكإند/02-البحث-والتحليلات.md).

## معايير قبول

- [ ] بحث بالدم + الموقع يعيد نتائج من API.
- [ ] قائمة المراكز + مخزون من `/centers`.
- [ ] المحافظات/المديريات تعمل offline بعد أول sync.
- [ ] الخريطة تعرض المتبرعين من آخر بحث ناجح.
- [ ] لا Firestore في مسار البحث.

# نقاط الربط مع الباكإند — خريطة الملفات (تعليقات `BACKEND` في الكود)

يُحدَّث هذا الملف عند إضافة تعليقات جديدة أو إزالة ملفات قديمة.

| المسار | موضوع للباكإند |
|--------|----------------|
| [`lib/core/app_constants.dart`](../../lib/core/app_constants.dart) | مفاتيح FCM legacy — يجب إزالتها؛ الإرسال على السيرفر فقط |
| [`lib/data/repositories/auth_repo_impl.dart`](../../lib/data/repositories/auth_repo_impl.dart) | استبدال بالكامل بـ `POST /auth/*`؛ لا إنشاء مستندات Firestore من العميل |
| [`lib/data/repositories/search_repo_impl.dart`](../../lib/data/repositories/search_repo_impl.dart) | `GET /donor-search` و `/manual`؛ لا استعلام محلي لكل المحافظة |
| [`lib/data/repositories/profile_repository_impl.dart`](../../lib/data/repositories/profile_repository_impl.dart) | `GET/PATCH /donors/me` و `/centers/me` |
| [`lib/data/repositories/global_repo_impl.dart`](../../lib/data/repositories/global_repo_impl.dart) | `GET /app-config` + `GET /files/:id` |
| [`lib/data/repositories/send_notfication_impl.dart`](../../lib/data/repositories/send_notfication_impl.dart) | حذف — الإرسال عبر API فقط |
| [`lib/core/check_active.dart`](../../lib/core/check_active.dart) | حالة المستخدم من JWT + `GET .../me`؛ لا Firestore للتحقق من `ACTIVE` |
| [`lib/core/update.dart`](../../lib/core/update.dart) | `min_app_version` من `app-config` |
| [`lib/core/methode/shared_method.dart`](../../lib/core/methode/shared_method.dart) | تحديث توكن الجهاز عبر `POST /auth/device` فقط |
| [`lib/presentation/cubit/search_cubit/search_cubit.dart`](../../lib/presentation/cubit/search_cubit/search_cubit.dart) | إزالة `search_logs` — السيرفر يسجّل |
| [`lib/presentation/cubit/signup_cubit/signup_cubit.dart`](../../lib/presentation/cubit/signup_cubit/signup_cubit.dart) | إزالة `users_per_day` — حد التسجيل في السيرفر |
| [`lib/presentation/cubit/signin_cubit/signin_cubit.dart`](../../lib/presentation/cubit/signin_cubit/signin_cubit.dart) | تسجيل دخول عبر API؛ إزالة كتابة Firestore للإحصاء |
| [`lib/presentation/pages/home_page.dart`](../../lib/presentation/pages/home_page.dart) | إزالة `pushNotifications*` و seeding `donors` |

## للمراجعات الفنية

# 02 — التخزين المحلي

## الهدف

استبدال Hive بتخزين آمن للجلسة، preferences للإعدادات الصغيرة، وDrift للبيانات الكبيرة (كاش المواقع).

## الوضع الحالي

| الاستخدام | التقنية | ملف |
|-----------|---------|-----|
| جلسة متبرع | Hive | `lib/data/models/donor_hive_data.dart` |
| مقارنة Hive/Firestore | Hive | `compare_hive_firbaase.dart` |
| لا تخزين tokens | — | — |

## الاستراتيجية المستهدفة

| نوع البيانات | الأداة | أمثلة |
|--------------|--------|-------|
| accessToken, refreshToken | `flutter_secure_storage` | `access_token`, `refresh_token` |
| userId, role | secure storage | `user_id`, `role` |
| onboarding، آخر تبويب | `shared_preferences` | `onboarding_done` |
| **device UUID** (`x-device-id`) | **`shared_preferences`** | ليس سراً — ثابت لكل تثبيت |
| تنسيق هاتف محفوظ | prefs اختياري | تطبيع `9677XXXXXXXX` عند العرض فقط |
| states/districts كاش | **Drift** | جداول `states`, `districts` |
| metadata كاش | Drift | `cache_meta(key, updated_at)` |

## Drift — نموذج مقترح

```text
lib/data/local/database/
  app_database.dart
  tables/
    locations_table.dart      # stateId, nameAr, ...
    districts_table.dart      # districtId, stateId, nameAr, ...
    cache_meta_table.dart     # key, fetchedAt
```

- **TTL للمواقع:** 7 أيام (قابل للتعديل) — عند انتهاء TTL أعد `GET /locations`.
- لا تخزّن كلمات مرور في أي مكان.

## SessionLocalDataSource (إنشاء)

```text
lib/data/datasources/local/
  session_local_datasource.dart    # secure: tokens, role, userId
  preferences_local_datasource.dart
  locations_local_datasource.dart  # Drift read/write
```

واجهة مقترحة:

```dart
abstract class SessionLocalDataSource {
  Future<void> saveSession({required String access, required String refresh, ...});
  Future<String?> getAccessToken();
  Future<void> clearSession();
}
```

## معايير قبول

- [ ] حفظ/قراءة tokens بعد login — إعادة فتح التطبيق يبقي الجلسة.
- [ ] `clearSession` يمسح secure storage بالكامل عند logout.
- [ ] تحميل locations من API مرة ثم القراءة من Drift offline.
- [ ] لا ملفات Hive متبقية في المشروع.
- [ ] iOS/Web: استخدم `FlutterSecureStorage` options مناسبة (Keychain / web wrapper لاحقاً).

## مخاطر

| الخطر | التخفيف |
|-------|---------|
| فقدان جلسة بعد تحديث التطبيق | migration script لمرة واحدة إن لزم |
| حجم Drift | فقط locations + بيانات ضرورية — لا تخزين نتائج بحث كاملة افتراضياً |

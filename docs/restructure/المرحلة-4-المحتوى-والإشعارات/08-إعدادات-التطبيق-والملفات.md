# 08 — إعدادات التطبيق والملفات

## الهدف

استبدال `global_app_data` + Firebase Storage بـ `/app-config` و `/files/*`.

## الوضع الحالي

| الملف | السلوك |
|-------|--------|
| `global_repo_impl.dart` | Firestore doc + `getDownloadURL` من Storage |
| `global_cubit.dart` | `getGlobalData()` |
| `home_carousel.dart`, `home_info.dart` | عرض سلايدر وفعاليات |
| `update.dart` | Firestore `updating` لإجبار التحديث |
| `domain/entities/global_app_data.dart` | حقول السلايدر |

## API المرجعي

[`docs/backend_guide/api/files-and-app-config.md`](../../backend_guide/api/files-and-app-config.md)

| Method | Path | Auth |
|--------|------|------|
| GET | `/app-config` | لا |
| GET | `/app-config/:key` | لا |
| POST | `/files/upload` | JWT |
| GET | `/files/:fileId` | اختياري |
| DELETE | `/files/:fileId` | JWT owner |

### مفاتيح app-config

**موثّق رسمياً في الدليل:** `app_name`, `home_header`, `min_app_version` (في استجابة `GET /app-config`).

**غير مضمون في المثال — تحقق من السيرفر قبل التنفيذ:**

| محتمل | استبدال Firestore |
|-------|-------------------|
| سلايدر الرئيسية | `global_app_data.home_slider` → قد يكون مفتاحاً منفصلاً `GET /app-config/:key` بقيمة JSON |
| الفعاليات | `events` |
| رسالة تحديث إجبارية | `min_app_version` + رابط المتجر محلي (`Urls.googleStoreAppLink`) |

**إجراء قبل كود:** `curl https://nabdh.telqaia.com/api/v1/app-config` وسجّل المفاتيح في `tasks/migration_master.md` → Context.

## AppConfigBloc

### Events

- `AppConfigLoadRequested` (عند splash/home)
- `AppVersionCheckRequested` (مقارنة `min_app_version` مع `package_info`)

### States

- `AppConfigLoading`, `AppConfigLoaded(AppConfigData)`, `AppConfigFailure`
- `AppUpdateRequired` (إن كان إصدار التطبيق < min)

## عرض الصور

- السلايدر: كل عنصر يحمل `fileId` → بناء URL عبر `ApiClient.getFileUrl(fileId)` أو استجابة `GET /files/:id`.
- لا `FirebaseStorage.ref`.

## Force update (يمكن جزءاً من مرحلة 0/1)

استبدال `lib/core/update.dart` (Firestore `updating`):

| قديم | جديد |
|------|------|
| `new_version`, `show_dialog`, `message` | `min_app_version` من `GET /app-config` |
| `update_link` | `Urls.googleStoreAppLink` أو مفتاح config إن وُجد |

قارن إصدار `package_info` مع `min_app_version` (semver بسيط). اعرض dialog من `AppConfigBloc` في Splash أو Home.

## الملفات — إنشاء / تعديل / حذف

| إجراء | مسار |
|-------|------|
| إنشاء | `app_config_remote_datasource.dart`, `files_remote_datasource.dart` |
| إعادة كتابة | `global_repo_impl.dart` → `app_config_repository_impl.dart` |
| إنشاء | `presentation/blocs/app_config/` |
| تعديل | `splash_screen.dart`, `home_page.dart`, `home_carousel.dart` |
| **حذف في نفس المرحلة** | `global_cubit/` |
| **حذف/إعادة كتابة** | `lib/core/update.dart` — إزالة Firestore |
| حذف | استيراد `firebase_storage` |

## معايير قبول

- [ ] السلايدر والفعاليات تُحمّل من `/app-config`.
- [ ] force update يعمل عند إصدار قديم.
- [ ] رفع ملف (للملف الشخصي) يعمل عبر `/files/upload` (انظر 05).
- [ ] التطبيق يعمل عند فشل config (fallback نصوص محلية).

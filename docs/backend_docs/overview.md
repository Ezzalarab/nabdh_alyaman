# نظرة عامة — نبض اليمن (الباكإند)

## الفكرة

منصة لربط المتبرعين بالدم، مراكز جمع الدم، والمشرفين: حسابات JWT، بحث متبرعين (جغرافي ويدوي)، طلبات استغاثة مع إشعارات FCM محدودة الانتشار، ومخزون مراكز.

## الأدوار

| الدور | الوصف |
|-------|--------|
| `DONOR` | تطبيق المتبرع |
| `CENTER` | لوحة مركز التبرع |
| `ADMIN` | إدارة ومستخدمو دعم |

التحقق من الصلاحيات على السيرفر (`403` عند عدم التطابق).

## المكدس التقني

- NestJS + Prisma + PostgreSQL  
- إشعارات: Firebase Admin SDK (FCM) — **لا** استخدام مفتاح خادم Legacy من العميل  
- للحماية على الحافة: Cloudflare (طبقة إنتاج) — التفاصيل في مستودع الباكإند (`docs/2-operations/`) إن وُجدت هناك.

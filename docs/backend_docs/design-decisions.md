# قرارات تصميم ثابتة

لا تُخالَف دون موافقة صريحة من صاحب المنتج أو الم техني.

## بساطة وبنية البيانات

- **بدون Redis** للتخزين المؤقت أو الجلسات في هذه المرحلة.  
- **بدون PostGIS** — بحث المتبرعين جغرافياً عبر حقول `lat/lon` (Float) + صيغة Haversine في SQL خام.  
- **Cloudflare** كطبقة حماية أساسية أمام VPS (راجع دليل النشر).

## إشعارات FCM

- الإرسال **من السيرفر فقط** (Firebase Admin SDK).  
- انتشار الإشعار لطلب الدم يُقيَّد بعدد صغير من الأجهزة (انظر كود السيرفر ومستودع الباكإند؛ عقد الواجهة في `docs/backend_guide/api/blood-requests-and-notifications.md`).

## تعارض وثائق الكود

عند تعارض `docs/**/*.md` مع `src/`، يعتبر تنفيذ **`src/`** مرجعية التشغيل حتى تُحدَّث الوثائق.

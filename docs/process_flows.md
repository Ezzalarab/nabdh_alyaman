# الدليل التفصيلي لتدفق العمليات (Exhaustive Process Flows)

يقدم هذا المستند شرحاً دقيقاً لكل خطوة منطقية في العمليات الحساسة للتطبيق.

---

## 1. منطق البحث الذكي المتوسع (Smart Search Algorithm)
1. استقبال الطلب (الفصيلة، الموقع).
2. **الاستعلام الأول (نطاق 5 كم)**.
3. إذا كانت النتائج < 10: التوسع إلى **10 كم**.
4. إذا لم توجد نتائج: البحث في كامل **المديرية** ثم **المحافظة**.

---

## 2. دورة حياة طلب الاستغاثة (Emergency Request Lifecycle) [NEW]

هذا المسار يوضح عمل نظام "البث الذكي" المقترح:

1. **إنشاء الطلب**: يقوم المستخدم بنشر استغاثة (`POST /v1/requests`).
2. **محرك البث (Broadcast Engine)**:
    - السيرفر يحدد المتبرعين المطابقين (الفصيلة + الموقع).
    - استخراج FCM Tokens.
3. **التنفيذ**: إرسال إشعارات بدفعات (Batches).
4. **الاكتمال**: عند انتهاء التبرع، يتم تحديث الحالة إلى `FULFILLED` وإرسال إشعار شكر.

---

## 3. دورة حياة تحديث المخزون (Inventory Lifecycle)
1. المركز يعدل الكمية.
2. الباكإند يتحقق من الملكية.
3. معالجة ذرية (Atomic Update) في SQL.
4. إنشاء سجل معاملة (Transaction Log).

---

## 4. نظام معالجة الملفات الآمن (Secure Media Proxy)
1. التطبيق يطلب ملف عبر `UID`.
2. السيرفر يتحقق من الصلاحيات.
3. استخدام `X-Accel-Redirect` لتفريغ الحمل عن نود.
